# elquantile 0.1.0

- Six distinct quantile EL methods with one-sample and independent-group inference.
- Paired quantile-of-differences inference and fixed-family post-hoc tests.
- One-sample confidence-interval components and conservative interval hulls.
- Analytical, exact-count and Monte Carlo power and sample-size planning.
- Source mapping, extension guide, examples and base-R validation tests.
- Correct shifted-cell evaluation avoids floating-point jump reconstruction.
- Added an executable R Markdown vignette covering inference, corrections,
  post-hoc comparisons, planning, and numerical diagnostics.
- Vignette building uses optional knitr and rmarkdown dependencies.
